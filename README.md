# WeKnora-learn

我跟 AI 一起把 `D:/Project/WeKnora`(腾讯开源的 WeKnora 知识管理框架)从头到尾吃透的学习笔记。

## 目录结构

```
WeKnora-learn/
├── README.md            # 本文件,说明怎么用这套笔记
├── notes/               # 按层级整理的学习笔记
│   └── 01-最外层架构.md  # 第一步:从最外层看 WeKnora 是干嘛的、怎么分层
└── sessions/            # 每次对话的原始记录(防止 AI 失忆)
    └── 2026-08-27-最外层架构.md
```

## 阅读顺序

1. `notes/01-最外层架构.md` —— 先读这个,用大白话讲项目是干嘛的、有哪些大模块、之间怎么配合。

## 我们怎么学

- 每一步都从外到内,先看懂"这是啥",再下钻"怎么实现的"
- 每个笔记都用大白话,听不懂就让我重写
- 原始对话存 `sessions/`,整理后的笔记存 `notes/`
