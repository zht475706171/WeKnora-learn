## 关键发现(给 AI 自己看,防失忆)

### MCP 接入路径

```
DB 配置 → registerMCPTools(agent_service.go:262)
  → RegisterMCPTools(mcp_tool.go:411)
    → getOrCreateMCPClientWithOAuthRetry  // 建 Client
    → Client.Initialize()                  // 握手
    → Client.ListTools()                   // 拉工具清单
    → 每个 mcpTool 包成 MCPTool 注册进 ToolRegistry
```

**MCP 是运行时动态发现**——工具清单不在代码里,每次启 agent 连 MCP server 拉 `ListTools`。

### MCPTool 适配器(mcp_tool.go:20)

- **Name**:`mcp_{serviceName}_{toolName}`(防冲突,超 64 字符截断)
- **Description**:带 `[MCP Service: xxx (external)]` 前缀防 prompt injection
- **Parameters**:直接用 MCP server 给的 `InputSchema`
- **Execute**:走 `MCPManager.CallTool` 调远程,接 Approval 闸

### Skill 接入路径

```
文件系统扫描 → Manager.Initialize(manager.go:156)
  → DiscoverSkills() 扫所有 SkillDirs
  → 每个 SKILL.md 只读 frontmatter → SkillMetadata{name, description, basePath}
  → 缓存 metadata(Level 1)
  → formatSkillsMetadata 注入 system prompt
  → 注册 read_skill / execute_skill_script / list_sandbox_files 工具
```

**Skill 是静态发现 + 渐进加载**——启动时扫目录,Level 1 注入 system prompt,Level 2/3 模型按需 read_skill。

### Progressive Disclosure 三级(skill.go:32)

- **Level 1 元数据**(name+description):启动全加载,注入 system prompt
- **Level 2 指令**(SKILL.md 正文):`read_skill` 按需加载
- **Level 3 资源**(目录其他文件):`read_skill(file_path=...)` 按需加载

### Skill 工具注册门控(agent_service.go:414)

- `SkillsEnabled == true` → 注册 `read_skill`
- `SkillsEnabled + sandbox 非禁用` → 注册 `execute_skill_script`
- `SkillsEnabled + SessionFileStore 能力` → 注册 `list/read_sandbox_files`

### 两套对比表

| 维度 | MCP | Skill |
|---|---|---|
| 来源 | 外部 MCP server(网络/stdio) | 本地文件系统 |
| 工具发现 | 运行时 `ListTools` 动态拉 | 启动时 `DiscoverSkills` 静态扫 |
| 注册时机 | 每次启 agent 都重新连+注册 | 启动时注册 3 个固定内置工具 |
| 工具数量 | 不固定 | 固定 3 个 |
| 执行 | `MCPManager.CallTool` 调远程 | `Manager.ExecuteScript` 本地沙箱 |
| 人审闸 | 有(Approval gate) | 无(沙箱隔离) |
| OAuth | 有 | 无 |
| 隔离 | 靠 MCP server | 靠 sandbox(网络禁、文件限 skill 目录) |
| 命名 | `mcp_{service}_{tool}` 动态拼 | `read_skill` / `execute_skill_script` 固定名 |

### 本质区别

- **MCP**:外部独立程序,Host 通过网络/stdio 调,能力在 Server 里
- **Skill**:本地文件 + 沙箱脚本,Host 自己跑,能力在 Host 里(只是指令分册加载)

MCP 是"接外挂",Skill 是"翻分册说明书"。
