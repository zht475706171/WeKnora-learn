## 我做了什么

1. 看了 `docreader/README.md` —— 了解配置项和服务端口(50051)
2. 看了 `docreader/main.py` —— gRPC 服务入口,3 个 RPC:Read / ReadStream / ListEngines
3. 看了 `docreader/parser/parser.py` —— 调度入口,detect_effective_file_type(防 .doc 假装 .docx)
4. 看了 `docreader/parser/registry.py` —— 引擎注册表(builtin/markitdown/opendataloader)+ 文件类型映射 + 回退逻辑
5. 看了 `docreader/parser/pdf_parser.py`(全 1619 行)—— 这是重头戏:
   - 逐页分类(_classify_page):图片覆盖比 ≥ 0.5 或 文字少+有图 → 扫描页
   - 文本页:版面重建(多栏 XY 切割、字号推断标题、空格推断、隐藏文字过滤、页眉页脚去除、图表碎片清理、矢量图渲染)
   - 扫描页:pdfium 渲染成 JPEG,多进程并行渲染
   - _PDFIUM_LOCK 全局锁(C 库非线程安全)
   - 强制扫描模式 + 异常全图渲染兜底
6. 看了 `docreader/parser/docx2_parser.py` + `chain_parser.py` + `docx_parser.py`:
   - Docx2Parser = FirstParser(MarkitdownParser, DocxParser) 责任链
   - DocxParser:python-docx 抽段落/表格/图片,多 worker 并发
   - 兜底 _parse_using_simple_method 只抽文字不处理图片
7. 看了 `docreader/client/client.go` —— 确认 Go 后端通过 gRPC 调用 docreader

## 关键发现(给 AI 自己看,防失忆)

- docreader = 独立 Python gRPC 服务,端口 50051,只解析不存储不切片不调 LLM
- 输出统一是 Markdown + 内联 base64 图片(ReadStream 流式发图片防 gRPC 单消息超 50MB)
- PDF 难点是逐页分类 + 版面重建 + pdfium 非线程安全(全局锁+多进程)
- DOCX 走责任链:MarkItDown → 自研 DocxParser → 简版
- 引擎注册表有 builtin/markitdown/opendataloader,选不到自动回退 builtin
- detect_effective_file_type 检测 OLE magic 防止 .doc 假装 .docx
- 隐藏文字过滤顺便防 PDF prompt 注入
