## 关键发现(给 AI 自己看,防失忆)

### 工具三层结构

| 层 | 内容 | 白话 |
|---|---|---|
| 定义(Definition) | BaseTool{name, description, schema} | 工具的"名片",给模型看 |
| 内容(Content) | Tool 结构体 + 字段 | 工具的"身体",装干活的家伙 |
| 执行(Execute) | Execute(ctx, args) 方法 | 工具的"动作",真正干活 |

### 案例 1:knowledge_search(外部检索型)

- **定义**:`knowledge_search` 名 + 语义搜索描述 + schema(query/topK/knowledgeBases/filters)
- **内容**:KBStore / VectorStore / Embedder / RerankModel / ChatModel / LLMClient / GraphStore / WikiStore / seenChunks
- **执行 10 步**:
  1. 解析参数 + 授权校验
  2. 算输出预算
  3. `concurrentSearchByTargets` 按 embedding model 分组并发检索
  4. 双 rerank(rerankModel→chatModel fallback)
  5. `applyMMR`(lambda=0.7 Jaccard)去重冗余
  6. `deduplicateResults`(多 key+内容签名)
  7. `formatOutput` XML 格式 + seenChunks + retrieval_statistics 覆盖率
  8. 返回 ToolResult
- **关键设计**:
  - `seenChunks` 跨轮复用防重复推 token
  - `compositeScore`:0.6*modelScore + 0.3*baseScore + 0.1*sourceWeight
  - `rerankWithLLM`:15 个一批温度 0.1
  - 输出 XML 结构化,模型好解析

### 案例 2:thinking(思维辅助型)

- **定义**:`thinking` 名 + "深度思考复杂问题"描述 + schema(thought/thoughtNumber/totalThoughts/branchId/needsRevision)
- **内容**:`SequentialThinkingTool` 结构体,thoughtHistory + branches(纯内存,不落盘)
- **执行**:
  1. 解析参数
  2. `validate`:thought 非空 / thoughtNumber>=1 / totalThoughts>=1
  3. 动态调整 totalThoughts(模型可以中途加步骤)
  4. append thoughtHistory
  5. 处理 branches(branchId 分支思考)
  6. 返回 display_type:"thinking" + incomplete_steps 标志
- **关键设计**:
  - 纯内存不调外部服务
  - thoughtHistory 帮模型跨轮记住思考过程
  - branches 支持分支思考(一条路走不通回溯)
  - 动态调整 totalThoughts(不是固定步数)

### 案例 3:todo_write(状态追踪型)

- **定义**:`todo_write` 名 + "只管检索任务不管总结"描述 + schema(todos 列表)
- **内容**:`TodoWriteTool` 只有 BaseTool,无状态
- **执行**:
  1. 解析参数
  2. 补默认 task
  3. `generatePlanOutput` 格式化
  4. 返回 display_type:"plan"
- **关键设计**:
  - **无状态**:模型每次传完整列表,工具不存任何东西
  - 真状态在模型脑子里,工具只负责格式化展示给用户
  - `generatePlanOutput` 格式化计划 + 进度统计 + Important Reminder
  - display_type:"plan" 前端渲染成计划清单

### 三类工具横向对比

| 维度 | knowledge_search | thinking | todo_write |
|---|---|---|---|
| 类型 | 外部检索型 | 思维辅助型 | 状态追踪型 |
| 调外部服务 | 调(vector/embedder/rerank/LLM) | 不调(纯内存) | 不调 |
| 复杂度 | 最复杂(10 步 pipeline) | 中等(纯内存逻辑) | 最简单(格式化) |
| 状态 | seenChunks 跨轮复用 | thoughtHistory + branches | 无状态 |
| 输出 | XML 结构化 + 统计 | thinking 展示 + incomplete 标志 | plan 清单 + 进度统计 |
| 主要价值 | 给模型喂检索结果 | 帮模型理清思路 | 给用户看计划 |

### 工具的本质

工具是模型的"手和眼":
- **手**:执行动作(knowledge_search 检索 / shell_exec 跑命令 / delete_repo 删仓库)
- **眼**:获取信息(读 DB / 读文件 / 读 graph)
- **脑的外挂**:thinking 帮模型分步思考 / todo_write 帮模型追踪状态

工具不替模型做决策,只替模型干活 + 提供信息。模型是大脑,工具是手脚。
