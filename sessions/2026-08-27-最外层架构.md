## 关键发现(给 AI 自己看,防止失忆)

- WeKnora = 腾讯开源,Go 为主,带 Python 子服务
- 三大玩法:RAG 问答 / ReAct Agent / Wiki 模式
- 顶层 6 大模块:cmd / internal / frontend / docreader / mcp-server / cli
- 主数据流:上传→docreader 解析→Embedding→pgvector 入库;提问→Agent 循环→混合检索(向量+BM25+Rerank)→LLM 生成→带引用
- 数据库主力是 PostgreSQL+pgvector,可替换向量库/对象存储/LLM 厂商
- 部署支持 Docker Compose 和 K8s Helm
