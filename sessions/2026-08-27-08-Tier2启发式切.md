## 关键发现(给 AI 自己看,防失忆)

- 8 个正则优先级:FormFeed=100, NumberedSection=90, ChapterMarker=85, AllCaps=70, VisualSep=60, PageFooter=50, BlankBlock=40
- 优先级只影响同位置去重保留,不影响切的顺序(都是按 runeStart 升序)
- 逐行扫是为了用 inFence 状态机跳过代码块,全文正则做不到
- minChunkSize = ChunkSize/4,最小 50,是"封口的最小长度"
- applyOverlapAligned 3 级退化:窗口内边界 → target 附近换行符 → raw target
- Tier 2 不维护标题栈,ContextHeader 空(结构信号不够稳定,强维护会错乱)
- 超大 block 委托 SplitText,子 chunk 位置 Start = start + s.Start 还原
- dropBoundsInsideSpans 丢严格内部切点,边缘切点保留
- 7 种保护模式:表格/代码/LaTeX/图片/链接/行内代码(复用 splitter.go 的 protectedSpans)
