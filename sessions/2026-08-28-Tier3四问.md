## 关键发现(给 AI 自己看,防失忆)

- splitBySeparators 递归核心:piece > chunkSize 且 len(remaining) > 0 → splitBySeparators(p, remaining, chunkSize)
- 分隔符作独立 unit 保留(splits + matches 交错拼接),让 mergeUnits 决定塞哪个 chunk
- "太大"用 > 不 >=,等于刚好够不切
- "快满"含 headersLen 预留,封口条件 curLen+uLen+headersLen > chunkSize && len(current) > 0
- absoluteMaxSize=7500 是 embedding API 硬限制,超了强制 flush 无 overlap
- DefaultChunkOverlap=80,注释说 0 适合原子数据 / 80 通用 / 150-200 长叙事
- computeOverlap:maxOverlap = min(chunkOverlap, chunkSize - nextLen),防下个 chunk 超
- 窗口 = maxOverlap + 4(semanticOverlapLookbehind = 4,for \r\n\r\n)
- originalWindowStart = 窗口字数 - maxOverlap,边界 end 必须 ≥ 这个
- findSemanticOverlapBoundaryEndingAtOrAfter 3 级优先级 + 同级取最早 + hasMeaningfulTail + !insideProtected
- overlap 成为下个 chunk 开头,Start 用 overlap 第一个 unit 的原文偏移,位置不变量保住
